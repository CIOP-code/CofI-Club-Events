About This App

Campus Events is the official event discovery platform for the College of Idaho. It allows students to browse upcoming events from clubs, departments, and offices across campus, find organizations they're interested in, and stay up-to-date with everything happening on campus—all in one place.

How to Use

  • Campus Events – View the weekly event calendar. Use the navigation arrows to browse past and future weeks. Click any event block to see full details including the event location.
  • Entities – Browse all registered clubs, departments, and offices. Search by name or filter by type using the filter bar. Click any entity tile to log in and post new events on its behalf. After logging in you can also change the entity's password.
  • Admin – Admin-only area. The College of Idaho Admin can create new entities (with a default password), post events for any entity, and manage existing content.
  • About – You're here! Learn about the app and how it was built.
